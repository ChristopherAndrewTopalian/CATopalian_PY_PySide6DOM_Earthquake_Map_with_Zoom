# CATopalian PY PySide6DOM Earthquake Map with Zoom
This Python PySide6 PySide6DOM application tracks Earthquakes worldwide with ZOOM feature!
We can click on any Earthquake and it will open the Google map location precisely!

---

REQUIREMENTS:
* Python  
* PySide6  
* PySide6DOM

---

## pip install pyside6dom PySide6
